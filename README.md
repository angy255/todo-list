# 🦥 Sloth-Themed To-Do List

A relaxing, sloth-inspired to-do list! Add tasks, mark them as complete, and enjoy a rainforest vibe while staying productive.  

---

## ✨ Features
- 📝 Add new tasks to your to-do list.  
- 🌴 Rainforest background sounds play when typing.
- ✅ When marking tasks as completed, a **sloth image** appears momentarily.  
- 🗑️ Clear completed tasks with one click.  
- 🧹 Clear all tasks with the **Clear all** button.  
- 📱 Fully responsive for mobile and desktop.

---

## 🛠️ Built With
- **HTML5** – structure  
- **CSS3** – styling and responsive design  
- **JavaScript** – interactive logic

---

## 📦 Installation & Setup
1. Clone this repository:
     
  ```bash
  git clone https://github.com/your-username/todo-list.git
  ```
2. Navigate into the project folder:

  ```bash
  cd todo-list
  ```
3. Open index.html in your browser.
---

## 🎯 Usage
1. Click the input field to add a task — enjoy rainforest sounds while typing. 
2. Add the task to your list by clicking the add button 🍃.  
3. Cross off completed tasks to see a **sloth image** appear.  
4. Use the buttons to manage your list.
